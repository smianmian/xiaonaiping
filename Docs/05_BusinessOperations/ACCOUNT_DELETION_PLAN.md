# ACCOUNT_DELETION_PLAN.md

## 文档状态

- 项目：小奶瓶 / 宝宝成长记录
- 阶段：账号删除实现更新
- 日期：2026-06-14
- 当前结论：App 内已接入云端账号删除入口，最小后端已实现删除账号、备份和云端照片对象；生产删除 SLA 和正式域名仍需发布前确认

## 已确认事实

1. 第一版先做单人记录。
2. 第一版需要账号。
3. 第一版需要备份恢复。
4. 服务器需要存储宝宝照片原图。
5. 有账号就必须提供账号删除入口。

## 合理推断

1. 当前恢复密钥账号不采邮箱手机号；若正式上架前切到 Sign in with Apple，需要处理 token/账号解绑和云端数据删除。
2. 删除账号必须覆盖宝宝档案、记录、提醒、照片原图和对象存储资产。
3. 删除失败必须可重试，并给用户明确状态。

## 待我确认的问题

1. 生产隐私政策是否承诺立即删除云端数据。
2. 是否存在短期恢复窗口。
3. 删除处理 SLA。
4. 正式 API 域名和生产部署时间。

## 不进入第一版的功能

1. 客服代删作为唯一方式。
2. 邮件人工删除作为唯一方式。
3. 复杂账号安全中心。

## 推荐路径

设置/资料 -> 账号与备份 -> 删除云端账号与备份 -> 二次确认 -> 删除账号、云端备份和云端照片原图

## 删除范围

1. 账号记录。
2. 云端 JSON 备份中的宝宝档案、喂养、睡眠、排便、身高体重、疫苗提醒、里程碑和照片元数据。
3. 云端照片原图对象。
4. 删除审计记录保留删除时间、备份删除状态和照片删除数量，不保留宝宝内容。
5. 本地数据默认保留，用户可另行清空本地记录或删除宝宝档案。
6. Apple 登录 token 撤销，如未来使用 Sign in with Apple。

## 当前验证

`Backend/tests/test_api.py` 覆盖创建账号、备份上传/恢复、照片上传/下载、恢复密钥登录、账号删除以及删除后 token 失效。

## App Store 审核要求

1. App 内必须能找到删除账号入口。
2. Review Notes 必须说明删除路径。
3. 删除路径不能只要求联系客服。
4. 删除后云端照片和记录的处理时间必须在隐私政策中说明。
