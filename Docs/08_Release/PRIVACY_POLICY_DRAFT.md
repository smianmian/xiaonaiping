# 小奶瓶隐私政策草案

日期：2026-06-24

本草案用于 App Store 审核和正式隐私政策托管前的产品/工程对齐。正式发布前需要替换为可公开访问的 HTTPS URL，并按深圳市闪现生活科技有限公司主体、联系方式和实际服务器区域复核。

## 我们收集和处理的数据

小奶瓶用于父母或照护者记录宝宝成长。你主动填写或加入 App 的内容可能包括：

1. 宝宝昵称、出生日期、性别。
2. 喂养、睡眠、排便、身高体重、疫苗提醒、里程碑等成长记录。
3. 你主动从相册选择或拍摄并加入小奶瓶的宝宝照片。
4. 账号标识、手机号登录标识哈希、微信登录标识哈希、同步状态和删除审计状态。
5. 手机号登录所需验证码发送状态；正式短信服务商确认后补充服务商名称和区域。
6. 微信登录所需授权 code 换取的微信账号标识；正式微信开放平台配置确认后补充 AppID 和数据边界。
7. 第一方产品交互事件，例如账号创建、登录完成、云同步完成、云恢复完成、记录类型和提醒类型枚举。
8. Apple 原生 TestFlight / App Store Connect 崩溃诊断数据。
9. 你主动创建或加入的私密家庭组成员资格、邀请码和家庭共享记录。

我们不在第一版收集定位、通讯录、广告标识、付款信息、第三方广告数据、系统相册中的全部照片、宝宝记录明细作为埋点、照片文件名、照片 EXIF 或对象 key。

## 使用目的

我们使用这些数据用于：

1. 在本机展示宝宝档案、记录、时间线、月报和提醒。
2. 在你主动开启账号与同步后，提供换机恢复。
3. 保存你主动加入 App 的照片原图，便于同一账号恢复。
4. 处理账号删除、云端同步删除和云端照片删除。
5. 用第一方聚合行为事件了解核心路径是否跑通、改进产品体验和准备未来商业化漏斗。
6. 使用 Apple 原生崩溃诊断改进稳定性。
7. 在你主动创建或加入私密家庭组后，与受邀请成员共同记录宝宝档案、喂养、喝水、睡眠、排便、成长、疫苗和纪念日。

小奶瓶不提供医疗诊断、治疗建议或疫苗接种专业建议。疫苗模板只用于记录和提醒，实际安排应以医生和当地官方资料为准。

灵动岛、锁屏 Live Activity 和桌面/锁屏小组件只做状态展示，用于显示你主动记录或设置的今日摘要、下一次喝奶提醒、固定间隔等信息。保存新喂养时，如果已设置固定喝奶间隔，提醒顺延由你手动选择：可用 5 分钟一档选择不顺延或顺延 +5、+10、+15、+20、+25、+30 分钟。保存后，下一次提醒按本顿结束时间 + 固定间隔 + 顺延分钟重排；本顿无喂养时长时按本顿发生时间计算。顺延只改变下一次提醒时间，不新增持久化字段；小奶瓶不根据奶量、月龄、传感器或健康数据自动推算喂养时间，也不构成喂养建议。这些状态展示只反映用户主动记录的数据，不生成健康建议、压力提醒、喂养建议或医疗判断；小奶瓶不接入 HealthKit、传感器、医院系统或第三方健康数据源。

## 本地保存和云端同步

默认情况下，记录优先保存在 App 私有空间。开启账号与同步并登录后，小奶瓶会自动上传宝宝记录、照片元数据和用户主动加入 App 的照片原图到私有账号空间；用户也可以手动立即同步。

你可以选择创建私密家庭组，或在登录自己的账号后输入受信任照护者提供的邀请码加入。家庭组最多 6 名成员，成员可相互查看和记录宝宝档案、喂养、喝水、睡眠、排便、成长、疫苗和纪念日。家庭协作是异步同步，不是公开分享或实时共同编辑；记录冲突以较新的更新时间为准，删除优先。宝宝照片原图、照片元数据、喝奶提醒偏好、账号凭证、手机号和微信标识不会在家庭成员间共享。

所有成员都可随时退出家庭；家庭创建者可移除成员或更换邀请码。退出或被移除后，服务器会立即拒绝该账号继续读取或写入家庭共享记录；更换邀请码后旧邀请码立即失效。家庭创建者退出或删除账号时，家庭会转交给最早加入的仍在家庭中的成员；若没有其他成员，家庭组及其共享记录会被删除。已下载到成员设备的本地副本仍由该成员在 App 内管理或删除。

第一版账号支持手机号验证码和微信授权登录：

1. App 将会话令牌保存在 iOS Keychain。
2. 手机号登录只保存手机号的哈希标识，用于识别同一同步账号。
3. 微信登录只保存微信账号标识的哈希，用于识别同一同步账号。
4. 登录后 App 自动执行云同步；换机时使用绑定的手机号或微信登录同一账号即可恢复云端资料。

## 照片

小奶瓶只处理你主动选择或拍摄后加入 App 的照片，不会自动扫描或上传你的整个系统相册。云端照片通过需要登录令牌的私有接口访问，不提供公开长期 URL。

## 删除

你可以在 App 内删除单条记录、单张照片、宝宝档案和云端账号同步。

删除云端账号与同步时，服务器会删除：

1. 账号记录。
2. 云端 JSON 同步。
3. 云端照片原图对象。
4. 只保留不含宝宝内容的删除审计信息，例如删除时间和照片删除数量。
5. 撤销该账号的家庭成员资格；已存在的家庭共享记录保留给仍在家庭中的成员，除非家庭已没有成员。

当前工程实现为立即删除云端账号、同步、照片对象和该账号对应的第一方埋点事件。正式发布前，需要在生产部署中验证删除结果、对象存储生命周期和同步保留策略，并在公开隐私政策中写明最终 SLA。

## 第三方共享

第一版不接入第三方广告、归因、热力图或第三方分析 SDK。第一方产品交互事件只写入自有后端，使用 HMAC 后的账号哈希和白名单枚举属性，不用于跨 App/网站追踪。崩溃诊断使用 Apple 原生 TestFlight / App Store Connect 能力。手机号登录会使用短信服务商发送验证码，微信登录会使用微信开放平台完成授权。除你主动邀请或加入的私密家庭成员、Apple 平台服务、短信服务商、微信开放平台、必要云基础设施和法律要求外，我们不会出售或共享宝宝记录和照片；家庭成员间不共享照片原图或照片元数据。

## 儿童和家庭数据

小奶瓶面向父母或照护者使用，不面向儿童直接使用。宝宝照片和成长记录属于高敏感家庭数据，应由监护人或有权照护者录入和管理。

## 首发地区

第一版计划在目标 App Store 地区全球同步首发，不采用地区分批上线。发布前需要完成各目标地区适用的商店、隐私、儿童/未成年人、SDK 披露、服务器和数据处理合规复核；中国大陆适用的 APP 备案、ICP 和联网服务判断也属于同一轮门禁。App 内不按所在地封锁功能，可选择中国大陆或香港疫苗提醒模板；模板只用于记录和提醒，不提供医疗建议。
