## 已确认事实

1. 第一版目标是真实可上线 iOS App。
2. 第一版免费验证。
3. 第一版首发地区调整为中国大陆，香港第二批。

5. 涉及儿童、照片、家庭成长记录。

## 合理推断

1. 隐私政策、用户协议和 App Privacy Label 不能等到开发完再补。
2. 账号删除是审核阻断项。
3. 照片原图云备份需要在 Review Notes 和隐私标签中清楚说明。
4. 中国大陆 APP 备案、生产联网服务和 App Store Connect 大陆合规信息是第一版阻断项。
