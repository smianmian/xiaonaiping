# ACCEPTANCE_CRITERIA.md

## 文档状态

- 项目：小奶瓶 / 宝宝成长记录
- 阶段：验收标准初版
- 日期：2026-06-18

## 已确认事实

1. 第一版只验收 iOS 原生 App。
2. 第一版必须支持宝宝档案、纪念日、喂养、睡眠、排便、身高体重、照片时间线、疫苗提醒、月度成长报告。
3. 第一版支持多宝宝档案和最多 6 名成员的私密家庭协作。
4. 照片复制到 App 私有空间。
5. 后端服务器存储已确认用于账号下的同步恢复。
6. 服务器需要存储宝宝照片原图。
7. 第一版首发地区调整为中国大陆，香港第二批；App 内不做用户所在地功能封锁。
8. 疫苗提醒模板覆盖中国大陆 + 香港，并允许用户在 App 内切换模板地区。
9. 崩溃上报进入第一版，使用 Apple 原生渠道。
10. API 服务与对象存储区域需在发布前按合规策略确认。

## 合理推断

1. 所有记录类功能都必须支持新增、编辑、删除、空状态、错误状态。
2. 所有高频记录都必须在断网时可用。
3. 细节字段不能阻碍快速记录。

## 待我确认的问题

1. 付费 Apple Developer 账号开通时间。
2. 云端数据保留周期和删除 SLA。

## 不进入第一版的功能

1. macOS 验收。
2. 社区、公开分享、电商、订阅验收。

## 通用验收标准

每个功能完成前必须满足：

- [ ] 可以新增。
- [ ] 可以编辑。
- [ ] 可以删除。
- [ ] 有空状态。
- [ ] 有错误状态。
- [ ] 数据保存正确。
- [ ] 断网行为明确。
- [ ] iOS 小屏显示正常。
- [ ] 支持动态字体的基本可读性。
- [ ] 涉及敏感数据时，存储位置、删除方式、上传规则明确。
- [ ] 有可执行测试用例或手工验收步骤。

## 宝宝档案

### 用户目标

用户可以创建一个宝宝档案，作为所有记录的归属。

### 完成条件

- [ ] 可填写宝宝昵称。
- [ ] 可填写出生日期。
- [ ] 可选填性别。
- [ ] 可选设置头像。
- [ ] 可编辑档案。
- [ ] 可删除档案。
- [ ] 删除档案前有二次确认。
- [ ] 删除档案时说明会影响哪些记录。
- [ ] 未创建档案时首页显示温柔空状态。
- [x] 可新增、切换与删除多个宝宝档案；统计、进行中睡眠、疫苗和提醒偏好按当前宝宝隔离。

### 不接受的情况

- 未创建宝宝档案就产生无法归属的记录。
- 删除档案后仍残留不可见数据。

## 今日首页

### 用户目标

用户打开 App 后能立即看到宝宝今天状态，并快速记录。

### 完成条件

- [ ] 显示宝宝出生第几天。
- [ ] 显示今日喂养次数摘要。
- [ ] 显示今日睡眠摘要。
- [ ] 显示今日排便次数摘要。
- [ ] 提供喂养、睡眠、排便、照片的快速入口。
- [ ] 没有今日记录时显示空状态。
- [ ] 有进行中的睡眠时清楚显示。

### 不接受的情况

- 首页只做装饰，没有快速记录入口。
- 高频入口隐藏过深。

## 纪念日

### 用户目标

用户可以看到出生第几天、满月、百天等纪念节点。

### 完成条件

- [ ] 根据出生日期自动计算出生天数。
- [ ] 自动识别满月、百天等节点。
- [ ] 日期异常时显示可理解错误。
- [ ] 纪念日文案不制造焦虑。

### 不接受的情况

- 纪念日计算错误。
- 用医学或育儿结论替代纪念提示。

## 喂养记录

### 用户目标

用户可以快速记录一次喂养，并按需补充细节。

## 喝水记录

- [ ] 首页和记录页均可进入“喝水记录”。
- [ ] 可保存时间与 10ml 为步长的饮水量，并在当天列表删除。
- [ ] 喝水记录出现在最近记录并自动同步，不影响喝奶提醒。

## 夜间模式与 Live Activity

- [ ] 资料页可开启夜间模式，所有主页面使用深色低亮度背景与可读文字。
- [ ] 喝奶 Live Activity 的倒计时自动递减，锁屏卡片不使用高亮黄色背景。

### 完成条件

- [ ] 可记录时间。
- [ ] 可选择母乳、瓶喂、配方奶、辅食。
- [ ] 数量/时长为可选字段。
- [ ] 备注为可选字段。
- [ ] 可编辑和删除。
- [ ] 今日首页能反映新增记录。
- [ ] 断网时可保存到本地。
- [ ] 可手动设置下一次喝奶闹钟。
- [ ] 可取消已设置的喝奶闹钟。
- [ ] 喝奶闹钟时间必须晚于当前时间。
- [ ] 通知权限拒绝时，提醒时间仍可保留在喂养页，但必须提示不会弹出系统提醒。
- [ ] 自动提醒初始开启且间隔为 3 小时；用户可调整为 2/2.5/3/3.5/4 小时或暂停。
- [ ] 自动提醒开启后，保存喂养按本顿结束时间计算；无喂养时长时按本顿发生时间计算。
- [ ] 支持本次不提醒、暂停自动提醒；手动单次提醒不会被自动规则静默覆盖。
- [ ] FeedingReminderPreference 按宝宝档案隔离且不进入服务器同步包。

### 不接受的情况

- 不填数量或备注就无法保存。
- 记录后首页摘要不更新。
- 自动根据宝宝月龄或上一顿时间给出喂养建议。
- 自动根据本顿奶量决定顺延分钟数。
- 在未由用户选择间隔时自动创建提醒。
- 通知权限被拒绝时仍宣称系统闹钟已开启。

## 睡眠记录

### 用户目标

用户可以记录睡眠开始和结束，看到睡眠时长。

### 完成条件

- [ ] 可开始一次睡眠。
- [ ] 可结束进行中的睡眠。
- [ ] 可手动填写开始/结束时间。
- [ ] 支持未结束状态。
- [ ] 可编辑和删除。
- [ ] 时间顺序错误时提示。

### 不接受的情况

- 结束时间早于开始时间仍可保存。
- 进行中状态丢失。

## 排便记录

### 用户目标

用户可以快速记录排便，并在需要时补充颜色、形态、备注。

### 完成条件

- [ ] 可记录时间。
- [ ] 颜色为可选字段。
- [ ] 形态为可选字段。
- [ ] 备注为可选字段。
- [ ] 可编辑和删除。
- [ ] 今日首页能反映排便次数。

### 不接受的情况

- 强制用户填写颜色或形态。
- 用排便信息给出医疗诊断。

## 身高体重记录

### 用户目标

用户可以记录并回看宝宝成长指标。

### 完成条件

- [ ] 可记录日期。
- [ ] 可记录体重。
- [ ] 录入体重时可选择 kg 或 斤，并在保存后保留所选单位。
- [ ] 可记录身高。
- [ ] 身高和体重至少填写一项即可保存。
- [ ] 可查看历史列表。
- [ ] 可编辑和删除。

### 不接受的情况

- 输入单位不明确。
- 删除后趋势或列表仍显示旧数据。

## 宝宝照片时间线

### 用户目标

用户可以把宝宝照片保存到 App 内，形成成长时间线。

### 完成条件

- [ ] 可从相册选择照片。
- [ ] 可通过系统相机添加照片。
- [ ] 照片复制到 App 私有空间。
- [ ] 可为照片设置日期。
- [ ] 可删除 App 内照片。
- [ ] 相册权限被拒绝时有友好提示。

- 未经明确同意上传照片。

## 宝宝疫苗本

### 用户目标

用户可以按宝宝月龄查看接种计划，记录预约与实际接种日期，并选择中国大陆或香港模板。

### 完成条件

- [ ] 可新增接种记录。
- [ ] 可编辑计划接种日期。
- [ ] 可记录实际接种日期。
- [ ] 可删除接种记录。
- [ ] 可在待接种、已预约、已接种之间切换状态。
- [ ] 可按月龄时间线查看全部、待接种和已接种记录。
- [ ] 可在 App 内切换中国大陆 / 香港模板地区。
- [ ] 可选择中国大陆模板。
- [ ] 可选择香港模板。
- [ ] 模板生成后用户可编辑日期和备注。
- [ ] 同一地区模板重复生成时不重复添加同名提醒。
- [ ] 不提供医疗建议。

### 不接受的情况

- 把提醒文案写成医学诊断或强制建议。
- 用户无法记录或修改实际接种日期。

## 崩溃上报

### 用户目标

开发者可以发现影响使用的崩溃，同时不采集宝宝隐私内容。

### 完成条件

- [ ] 崩溃上报方案写入 `SDK_DATA_INVENTORY.md`。
- [ ] 不上传宝宝照片、照片对象 key、生日、记录明细、备注。
- [ ] App Store 隐私标签与实际行为一致。
- [ ] 用户隐私政策说明崩溃数据用途。

### 不接受的情况

- 崩溃日志包含宝宝内容或照片路径明文。
- 接入第三方 SDK 但未更新隐私审查。

## 月度成长报告

### 用户目标

用户可以查看宝宝某个月的成长记录总结。

### 完成条件

- [ ] 可选择月份。
- [ ] 聚合该月喂养、睡眠、排便、身高体重、照片、纪念日。
- [ ] 记录不足时显示友好空状态。
- [ ] 报告内容来自真实记录。
- [ ] 不伪造不存在的数据。

### 不接受的情况

- 记录不足时强行生成虚假总结。
- 报告页面无法追溯到原始记录。

## 多宝宝与私密家庭协作

### 用户目标

用户可在一个 App 内管理多个宝宝，并让受邀请的家庭照护者共同记录同一家庭组内的档案与记录。

### 完成条件

- [x] 可新增、切换、删除宝宝档案；删除一个宝宝不影响其他宝宝的记录。
- [x] 已登录用户可创建家庭或通过邀请码加入一个家庭；成员上限为 6。
- [x] 家庭成员共享宝宝档案、喂养、喝水、睡眠、排便、成长、疫苗和纪念日；照片原图仍只在各自账号范围内同步。
- [x] 无网络时照常本地记录；恢复网络后按单条记录更新时间合并，删除墓碑优先。
- [x] 成员可主动退出家庭；家庭创建者可移除成员并使旧邀请码失效，且受影响成员不能继续拉取或写入共享记录。
- [x] 家庭协作的成员可见范围、邀请码、退出/移除、冲突和删除语义已写入隐私政策与 App Store 隐私材料。
- [ ] 真机覆盖多宝宝切换、加入家庭、离线新增后合并、并发编辑、删除传播、成员退出/移除和邀请码失效。

### 不接受的情况

- 家庭成员可读取其他家庭的数据，或可读取共享家庭的照片原图。
- 被移除或退出的成员仍可拉取或写入共享记录。
- 多个宝宝的统计、提醒、疫苗或进行中睡眠相互串数据。

### 不接受的情况

- 未告知用户就上传宝宝数据。
- 没有删除机制。
- 使用第三方数据服务但未披露。
- 删除本地照片后云端原图仍不可控。
