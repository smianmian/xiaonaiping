# UX_FLOW.md

## 文档状态

- 项目：小奶瓶 / 宝宝成长记录
- 阶段：UX 流程初版
- 日期：2026-06-18

## 已确认事实

1. 第一版只做 iOS 原生 App。
2. 目标用户以妈妈为主。
3. 用户当前主要用微信记录，痛点是不好看、缺少成长档案感。
4. 第一版要服务每天多次打开、连续记录 30 天。
5. 细节字段作为备选项目，不能阻碍快速记录。
6. 第一版需要账号、同步恢复和照片原图云同步。
7. 第一版首发地区调整为中国大陆，香港第二批；App 内不做用户所在地功能封锁。
8. 疫苗模板覆盖中国大陆 + 香港，崩溃上报进入第一版并使用 Apple 原生渠道。
9. 第一版支持多宝宝档案和最多 6 名成员的私密家庭协作；照片原图不在成员间共享。

## 合理推断

1. 高频记录必须支持半夜、单手、疲惫、焦虑场景。
2. 首页应该让用户 1 步进入喂养、睡眠、排便、照片。
3. 所有表单应先给“可保存的最小记录”，再允许补充细节。
4. 空状态需要温柔，不制造“你没有好好记录”的压力。

## 首次启动流程

1. 打开 App。
2. 先看到 3 页水彩欢迎引导；第 1 页使用“欢迎来到小奶瓶”与奶瓶插画。
3. 点击“开始记录”进入建档；前两页点击“先看看”切到下一页，最后一页点击“先看看”进入无档案的主页面预览。
4. 创建宝宝档案：昵称、出生日期为核心字段；性别、头像可选。
5. 建档后进入今日首页；账号登录与自动同步不阻塞首次记录。

## 多宝宝与家庭协作流程

1. 用户在资料页添加、切换或删除宝宝档案；切换后首页、统计、进行中睡眠、疫苗和提醒偏好只显示当前宝宝。
2. 已登录用户在资料页创建家庭，得到邀请码；受邀请照护者登录自己的账号后输入邀请码加入。
3. 家庭成员共同记录宝宝档案、喂养、喝水、睡眠、排便、成长、疫苗和纪念日；照片原图仍按各自账号管理，不显示为家庭共享。
4. 保存始终先落本地；网络恢复后以单条记录增量同步，较新更新时间覆盖旧更新，删除优先。
5. 发布前必须提供退出家庭、移除成员和邀请码失效入口；入口说明撤销后无法继续访问共享记录，以及本机已有副本的处理方式。

### 空状态

- 未创建宝宝档案：提示“先为宝宝建一个小档案”，提供创建按钮。
- 已创建档案但无记录：提示“今天还没有记录，先记一件小事吧”，显示快速记录入口。

## 今日首页流程

1. 显示宝宝昵称、出生第几天、纪念日提示。
2. 显示今日摘要：喂养、睡眠、排便、照片。
3. 显示快速记录按钮：喂养、睡眠、排便、照片。
4. 下方展示最近记录时间线。

### 疲劳场景检查

- 高频按钮必须可单手点击。
- 不应要求用户在保存前填写大量字段。
- 默认使用当前时间。
- 用户可以之后编辑细节。

## 喂养记录流程

1. 点击“喂养”。
2. 默认时间为当前时间。
3. 选择类型：母乳、瓶喂、配方奶、辅食。
4. 可选填写数量、时长、备注。
5. 保存并返回首页。

## 喝奶闹钟流程

1. 进入“喂养记录”。
2. 用户可选择具体时间并保存“本次手动提醒”；该提醒优先于自动规则。
3. 自动提醒初始为 3 小时；用户可调整为 2/2.5/3/3.5/4 小时或暂停。
4. 保存喂养时，自动提醒按结束时间（无时长则发生时间）加用户所选间隔重排；选择“本次不提醒”只跳过自动提醒。
5. 如果 iOS 通知权限可用，加入本地通知；被拒绝时仍保存提醒意图并清楚说明不会弹出系统提醒。
6. 用户可暂停自动提醒或取消当前提醒；系统不会反复弹出权限请求。

### 边界

- 不根据宝宝月龄、上一顿时间或奶量自动推荐喂养间隔。
- 单次手动提醒不因保存喂养而被自动规则静默覆盖。
- 自动提醒偏好按宝宝档案隔离，且不进入服务器同步。
- 换宝宝档案、删除本地记录或恢复云端同步时，清除旧喝奶闹钟。

### 空状态

- 今日无喂养记录时显示柔和提示和新增入口。

### 错误状态

- 数量格式错误时提示用户修正。
- 保存失败时保留表单内容，不丢失输入。
- 喝奶闹钟时间早于当前时间时提示用户重新选择。

## 睡眠记录流程

1. 首页点击“开始睡眠”。
2. 首页显示进行中的睡眠状态。
3. 宝宝醒来时点击“结束睡眠”。
4. 可进入编辑页修正开始/结束时间。

### 错误状态

- 结束时间早于开始时间时不能保存。
- 如果存在进行中睡眠，再次开始时提示处理上一段睡眠。

## 排便记录流程

1. 点击“排便”。
2. 默认只需记录当前时间。
3. 可选选择颜色、形态、备注。
4. 保存并返回首页。

### 错误状态

- 可选项缺失不算错误。
- 保存失败时保留输入内容。

## 照片时间线流程

1. 点击“照片”或进入时间线。
2. 选择拍照或从相册选择。
3. 系统权限弹窗由 iOS 触发。
4. 选择照片后复制到 App 私有空间。
5. 用户可设置日期和备注。
6. 照片出现在宝宝时间线。

### 权限状态

- 相册权限拒绝：显示去系统设置的说明。
- 相机权限拒绝：显示替代入口“从相册选择”。

## 疫苗提醒流程

1. 进入疫苗提醒。
2. 在模板地区里切换中国大陆或香港。
3. 生成对应地区的提醒草稿，或手动新增。
4. 模板生成提醒后，用户可以编辑名称、日期、备注。
5. 到期前通过本地通知提醒。
6. 用户可标记完成。

### 边界

- 第一版不提供医疗建议。
- 中国大陆 + 香港模板只作为提醒模板，不提供医疗建议。

## 月度成长报告流程

1. 进入“月报”。
2. 默认显示最近一个月。
3. 聚合该月照片、喂养、睡眠、排便、身高体重、纪念日。
4. 记录不足时显示温柔空状态。

### 边界

- 不伪造不存在的数据。
- 不把报告写成医学判断。

## 数据删除流程

1. 用户进入设置或档案管理。
2. 选择删除单条记录、单张照片或宝宝档案。
3. 高风险删除需要二次确认。
4. 删除照片必须说明本地和云端原图删除结果。
5. 删除账号必须说明账号、记录、云端照片和同步数据的删除结果。

## 断网流程

1. 所有记录先写入本地。
2. 无网络时不阻止记录。
3. 断网期间显示待同步状态。
4. 恢复网络后再同步。

## 安静育儿模式流程

1. 默认开启安静育儿模式。
2. 用户进入资料页，可关闭或重新开启。
3. 开启后，App 内白噪音播放入口不可误触发，今日关键记录字号放大一档。
4. 文案表达保持低刺激，不用催促、警告或责备语气。

## 桌面/锁屏小组件流程

1. 主 App 保存记录后写入 App Group 今日快照。
2. 桌面小组件展示宝宝昵称、出生天数、今日喂养、今日奶量、睡眠状态和排便次数。
3. 锁屏小组件优先展示下一次喝奶提醒；没有提醒时展示上次喂养距今多久。
4. 未创建宝宝档案或暂无快照时，引导打开 App 建档或记录。
5. 小组件一期只读，不提供记录按钮、照片展示、备注展示或账号/同步信息。

## 喝奶节奏提醒流程

1. 用户在喝奶闹钟卡片选择下一次提醒时间。
2. 用户选择“只一次”或 2/2.5/3/3.5/4 小时固定间隔继续提醒。
3. 用户新增喂养时，若已有固定喝奶间隔，可用 5 分钟一档滚动选择把本顿下一次提醒顺延 0-30 分钟。
4. 保存后，本机按本顿结束时间 + 固定间隔 + 顺延分钟重排未来本地通知，并同步桌面小组件、锁屏小组件和灵动岛/锁屏 Live Activity 的下一次提醒展示。

## 喝水记录流程

1. 从首页或“记录”页点击“记喝水”。
2. 选择发生时间和饮水量后保存。
3. 今日概览和最近记录立即更新；该记录随账号自动同步。
5. 用户取消喝奶闹钟时，同时取消本地通知和 Live Activity。
6. 该能力只表达用户主动设置的照护节奏，不自动根据奶量推算、不提供医疗建议。
