# BRAND_TYPEFACE_SPEC.md

## 小奶瓶体

### 目标

“小奶瓶体”是小奶瓶 App 的原创界面字体：笔画圆润、略带手写温度，但在 12pt 至 20pt 的记录、表单和按钮中仍清楚可读。

### 字形规则

1. 两个字重：Regular（正文）与 Medium（标题、按钮、Tab）。
2. 标题允许轻微手写起收笔；正文的横、竖、数字和标点保持稳定，不能模仿潦草童书字。
3. 数字需采用等宽数字，方便奶量、时长、身高和体重对齐。
4. 支持简体中文、繁体中文、英文、阿拉伯数字、常用单位、日期和全角标点。
5. 用户输入或系统控件遇到未覆盖字形时回退到 PingFang SC，绝不显示缺字方块。

### App 映射

| 场景 | 字重 | 说明 |
|---|---|---|
| 开屏标题、页面标题、按钮、Tab | Medium | 保留温柔的手写识别度 |
| 卡片标题、记录正文 | Regular | 易扫读 |
| 日期、奶量、身高体重、表单 | Regular + 等宽数字 | 优先可读性 |
| 系统 Picker、DatePicker、辅助说明 | 系统回退 | 遵循 iOS 可读性与动态字体 |

### 交付要求

1. 字体以 `.otf` 或 `.ttf` 随 App 打包，包含版权和授权文件。
2. 当前 Swift 源码首轮字形普查得到 608 个去重的中文、拉丁、数字、单位与标点字符；字体生产先保证这组静态界面字符集，再扩展常用中文字符集。
3. 完成完整常用中文字符集与全部 App 静态文案覆盖后，再替换临时系统回退。
4. 不使用设备内置字体改名冒充原创字体，也不使用来源不明的商用字体。
