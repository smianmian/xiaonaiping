## 已确认事实

1. 产品处理宝宝照片、出生日期、喂养、喝奶闹钟、睡眠、排便、身高体重、疫苗提醒等高敏感家庭数据。
2. 第一版只做 iOS 原生 App。
3. 数据本地优先。
4. 第一版需要账号。
5. 第一版需要备份恢复。
6. 服务器需要存储宝宝照片原图。
7. 照片可以复制进 App 私有空间。
8. 首发地区改为中国大陆，香港第二批。
9. 第一版免费验证，不做广告、电商、订阅。
10. 疫苗提醒模板覆盖国内 + 香港。
11. 崩溃上报进入第一版。
12. 崩溃上报使用 Apple 原生渠道。
13. API 服务器和对象存储第一版默认按合规策略确认。
14. 当前最小后端实现路径为 `Backend/api/server.py`。
15. 当前 iOS 接入路径为资料页“账号与备份”。
16. 第一方合规埋点只采集白名单行为事件，不采集宝宝内容、照片、手机号、微信标识或定位。

## 合理推断

1. 本 App 应避免追踪、广告、第三方分析 SDK。
2. 后端服务器存储必须有明确用户告知、隐私政策、删除机制和安全设计。
3. 照片原图云备份是第一版最高隐私风险点。
4. 疫苗提醒只能做日程提醒，不能做医疗建议。
5. App Store 隐私标签必须披露账号、用户内容、照片/视频、健康或成长相关数据。
6. 中国大陆首发需完成儿童个人信息、敏感个人信息、备案、App Privacy Label 和账号删除闭环。
7. 崩溃上报不得包含宝宝内容、照片对象 key、记录明细、账号 token 或服务器密钥。
8. 第一方产品使用数据应作为 Usage Data / Product Interaction 披露，用途为 Analytics，不得用于 Tracking。

## 第三方 SDK

第一版默认不允许接入广告、归因、热力图或第三方分析 SDK。账号、备份、对象存储和合规埋点通过自有 API 完成，避免在客户端直接接入不必要云厂商 SDK。

## 服务器存储隐私要求

已完成的最小实现：

1. 账号方式：恢复密钥账号，会话 token 存 Keychain。
2. 上传字段清单：云端 JSON 备份包含宝宝档案、记录、提醒、里程碑、照片元数据；照片原图单独上传。
3. 访问控制：所有备份和照片接口要求 Bearer token。
4. 缩略图：当前不上传缩略图。
5. 用户删除云端记录和照片机制：单张照片删除和账号删除 API 已实现。
6. 账号删除机制：资料页内可触发云端账号和备份删除。
7. 第一方合规埋点：只保存 HMAC 账号哈希、事件名、时间和白名单枚举属性；账号删除时同步删除。
8. 隐私政策文案：`Docs/08_Release/PRIVACY_POLICY_DRAFT.md`。

发布前仍必须补齐：

1. 正式 HTTPS API 域名。
2. 生产对象存储区域和生命周期策略。
3. 生产删除 SLA 和备份保留规则。
4. 服务端日志脱敏证据：`Backend/proof/diagnostics-redaction.json` 已通过，后端照片对象路径会记录为 `/v1/photos/<redacted>`。
5. 生产远端验证证据：`Backend/proof/remote-api.json`。
6. App Store Connect 隐私标签截图或导出。
7. Apple 原生崩溃上报真实样本脱敏截图或导出。

## App Store 隐私标签初步判断

| 类别 | 可能需要披露 | 说明 |
|---|---:|---|
| Health and Fitness | 是 | 喂养、睡眠、成长记录可能被视为健康/成长相关 |
| Photos or Videos | 是 | 用户导入并云备份宝宝照片原图 |
| User Content | 是 | 用户备注、照片、记录 |
| Identifiers | 是 | 账号和服务器用户 ID |
| Contact Info | 是 | 手机号登录验证码，如启用手机号登录 |
| Usage Data | 是 | 第一方产品交互事件，用于 Analytics，不用于 Tracking |
| Diagnostics | 是 | 崩溃上报进入第一版 |
| Location | 否 | 第一版不使用 |
| Contacts | 否 | 第一版不使用 |
| Purchases | 否 | 第一版不商业化 |

## 用户删除数据机制

第一版必须提供：

1. 删除单条记录。
2. 删除单张本地和云端照片。
3. 删除宝宝档案及全部关联数据。
4. 删除账号及云端备份数据。
5. 删除失败重试状态。
6. 删除前说明影响范围，删除后给出结果反馈。

## 风险结论

### 当前可继续

可以继续做生产部署、TestFlight、App Store Connect 元数据、截图、隐私政策托管和发布证据补全。

### 当前不可做

在以下问题确认前，不允许提交 App Store 正式审核：

1. 正式 API 域名和 HTTPS 可访问。
2. 生产对象存储私有访问和备份策略。
3. 照片删除 SLA。
4. 隐私政策 URL 和 App Store 标签。
5. TestFlight / App Store Connect 真实崩溃样本脱敏截图或导出。

### 高风险项

1. 照片原图云端泄露。
2. 用户无法删除云端照片。
3. 疫苗提醒被表达成医疗建议。
4. 后端日志记录敏感明文。
5. 第三方 SDK 采集儿童或家庭数据。
6. 崩溃日志带出照片路径、对象 key、token 或宝宝记录内容。

## Widget 与锁屏隐私补充

1. 桌面/锁屏小组件只读取 App Group 内的最小今日快照。
2. 快照不包含宝宝照片、备注全文、账号、恢复密钥、云端 token、对象 key 或备份状态。
3. 锁屏和灵动岛展示优先控制在上次喂养、下一次喝奶提醒、固定间隔、睡眠进行中和今日计数级别。
4. 用户删除宝宝档案、清空本地记录或恢复云端备份后，主 App 会随本地状态更新共享快照。
