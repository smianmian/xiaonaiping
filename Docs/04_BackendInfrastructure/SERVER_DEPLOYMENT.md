## 合理推断

1. 服务器和对象存储区域必须匹配首发地区、隐私政策和 App Store 隐私披露。
2. 中国大陆服务器会触发 APP 备案 / ICP 判断，必须作为首发路径的一部分同步推进。
3. 隐私政策 URL 和 API 域名也要规划。

## 同机部署边界

公开仓库只保留原则，不记录真实服务器、目录、端口、进程名、域名或运维面板入口。

当前部署证据见 `Backend/proof/huawei-baota-deploy-20260620.json` 和 `Backend/proof/remote-api.json`。该证据只记录非密钥状态和隔离关系，不包含密码、token、AK/SK 或服务器面板入口。

公网过渡路径只开放 App API、隐私政策、用户协议和支持页；`/xiaonaiping/internal` 与 `/xiaonaiping/internal/` 已由 Nginx 返回 404。看板仍应通过服务器本机、SSH 隧道、VPN 或等效内网方式访问。

如果小奶瓶与其他服务同机：

- 小奶瓶必须有独立部署目录、内部端口、进程名、日志路径和反向代理站点。
- 小奶瓶必须有独立 MySQL 数据库和数据库账号，禁止复用情绪 App / 一根呆毛库或账号。
- 部署命令必须只作用于小奶瓶自己的目录和进程。
- 禁止复用、覆盖、迁移、重启或清理同机已有服务。
- 具体部署参数只允许保存在私有运维文档或服务器环境配置中。

## 禁止事项

1. 不在公开文档里写真实 IP、密码、AK/SK、运维入口、端口、目录或域名。
2. 未完成适用备案和生产验证，不得提交中国大陆 App Store。
3. 不用可能影响同机其他服务的全量命令作为交付指令。
