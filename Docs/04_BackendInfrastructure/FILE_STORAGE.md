## 已确认事实

1. 照片可以复制进 App 私有空间。
2. 服务器需要存储宝宝照片原图。
3. 第一版需要账号和同步恢复。
4. 宝宝照片属于高敏感家庭数据。
5. 第一版全球同步首发，不采用地区分批上线。
6. 对象存储第一版默认按合规策略确认。

## 合理推断

1. 云端照片原图应使用私有对象存储，默认候选为对象存储。
2. 照片原图上传必须用户知情，不能自动上传系统相册。
3. 需要同时管理本地文件、缩略图、云端对象和删除状态。
4. 照片不应用于分析、训练、推荐或运营。

## 待我确认的问题

1. 是否生成和上传缩略图。
2. 是否压缩原图或保留原始质量。
3. 云端照片删除 SLA 是否承诺立即删除。
4. 生产对象存储区域。

## 不进入第一版的功能

1. 第三方云相册。
2. 公开照片分享。
3. 照片 AI 识别。
4. 自动上传系统相册全部照片。
5. 全球首发对象存储与跨地区数据处理安排。

## 本地文件规则

1. 用户主动选择或拍摄的照片复制进 App 私有空间。
2. 删除 App 内照片时，同时删除本地原图和缩略图。
3. 不保存外部相册永久引用作为唯一来源。
4. 本地文件删除失败必须可重试或提示。

## 云端文件规则

当前最小实现：`XNP_DATA_DIR/objects/{accountId}/photos/{photoId}.bin` 私有目录。

生产默认候选：对象存储或同等私有对象存储。当前代码已支持 `XNP_STORAGE_BACKEND=huawei_obs`，通过服务端可选依赖 `esdk-obs-python` 接入华为云 OBS；客户端仍只访问小奶瓶自有 API，不持有对象存储凭证。

必须明确：

1. 存储区域：发布前按合规策略确认。
2. 私有桶 / 私有访问策略。
3. 文件命名规则：当前使用照片 UUID，不包含宝宝姓名或生日。
4. 上传鉴权方式：Bearer 会话 token。
5. 是否生成缩略图：当前不上传缩略图。
6. 删除机制：单张照片删除和账号删除均会删除对象文件或 OBS object。
7. 保留周期：待生产隐私政策确认。
8. 用户端明确同意和状态展示：资料页“账号与同步”中展示并由用户主动触发。

## 云端照片删除要求

1. 删除单张照片时删除云端原图和缩略图。
2. 删除宝宝档案时删除该宝宝全部云端照片。
3. 删除账号时删除账号下全部云端照片。
4. 删除失败必须进入重试队列。
5. 删除 SLA 必须写入隐私政策。
