## 已确认事实

1. 第一版需要账号。
2. 第一版需要同步恢复。
3. 第一版服务器需要存储照片原图。
4. 第一版支持最多 6 名成员的私密家庭协作；成员只共享档案与记录，不共享照片原图。
5. 第一版不做用户内容管理后台；仅保留受内网和管理员令牌保护的聚合运维指标。
6. 数据高敏感。
7. API 服务与对象存储区域需在发布前按合规策略确认。

## 合理推断

1. 后端提供同步/恢复、私密家庭协作和文件存储；运维指标只能是聚合数据。
2. 不应在第一版做客服随意查看用户宝宝数据的后台。
3. 服务端日志必须避免敏感明文。
4. 照片应使用私有对象存储，不应公开可访问。

## 最小后端边界

1. 账号/身份：手机号验证码或微信登录，登录成功后自动开启云同步，客户端会话存 Keychain。
2. 同步 API：上传和恢复宝宝档案、记录、提醒、照片元数据。
3. 文件 API：上传、下载、删除用户主动加入 App 的照片原图。
4. 删除 API：删除账号、云端同步、照片对象和账号记录。
5. 同步状态：当前通过同步响应、照片列表和删除响应反馈最小状态。
6. 家庭协作 API：创建或加入一个家庭组；成员以游标增量同步允许类型的记录，按更新时间解决冲突；照片原图不进入家庭记录通道。

## 安全边界

1. 所有接口必须鉴权。
2. 不允许通过可猜 ID 访问数据。
3. 不允许服务端日志记录宝宝姓名、生日、备注、照片 URL 明文。
4. 不允许客服或后台随意查看宝宝数据。
5. 不允许把敏感数据交给第三方分析。
6. 对象存储必须私有访问。
7. 家庭成员退出、移除和邀请码失效必须在发布前实现；撤销后服务端必须拒绝该账号访问家庭记录。
